Phase 02 : Colour locked for redesigning @harvey

One mood, three colours, and one thing Harvey already owns but never uses.

The mood :
Bookish. A partner's office, not a startup. Plaster wall, ink, one green-shaded lamp. A legal buyer trusts a room like that, so every colour comes from something in it.

The ground :
Harvey's own ivory, #FAFAF9, measured from their live site. I tried a warmer plaster first and it read pink next to theirs. This is an improvement, not a rebrand, so the page stays on their ground.

The ink :
Their text is #0F0E0D. I kept it warm but pushed it a half-step darker and lifted the secondary gray so small text stops fading into the ivory. Never pure black.

The accent, and where it differs :
Harvey has a slate green in their hero texture, #333F40. It only ever appears as a background. Their buttons are black, their links are black, their deltas are a generic fintech green. So the one colour that is theirs does no work.

I took that green, nudged it slightly greener and a touch more saturated, and made it the action colour. Every primary button, every agent action, every "this is live" state now carries it. Black steps back to text. The result feels more like Harvey than Harvey does, because the colour was always there, it just was not being used.

Everything else is status: green for done, amber for in review, red for flags. All quiet, all from the same family, so the page never shouts.
